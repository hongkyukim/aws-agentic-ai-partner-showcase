# Partner booth questions

## AWS

- Which runtime and model-access pattern is recommended for this workload today?
- How are IAM, network isolation, secrets, tracing, and cost controls implemented?
- What is the supported path for human approval and rollback?
- Which metrics distinguish model quality from infrastructure failure?

## MongoDB

- What is the document model for operational records, decisions, and traces?
- Which indexes support the hot paths, and how is tenant isolation enforced?
- When should exact filtering beat vector search?
- How do we handle stale, conflicting, or deleted knowledge?

## Mastra

- When should a task be a workflow versus an autonomous agent?
- How are typed tools, retries, approvals, and durable state composed?
- What are the recommended evaluation and tracing hooks?
- How do we preserve application policy when the agent is allowed to plan?
